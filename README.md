# MecZuil Crosshair

外置游戏准星悬浮窗：无边框置顶透明窗口，在任意游戏画面上叠加自定义准星。

## 功能特性

- **双层准星**
  - 点心层：圆 / 方 / 三角 / 自定义图片
  - 聚焦层：`>` `<` `)` `V` `-` / 自定义图片，上、下、左、右四块可独立显隐
- **参数调节**：大小、自转角度、透明度、颜色（取色器或 `R,G,B` / `#RRGGBB` 输入），聚焦层额外支持粗细、与点心的距离（可为负）、公转角度
- **预设系统**：当前样式可保存为预设，随时一键切换；预设存为独立 ini 文件，可拷贝分享
- **锁定穿透**：锁定后窗口鼠标穿透、边框与状态栏隐藏，不影响游戏操作
- **全局热键**：默认 F9 呼出/隐藏状态栏，可在设置面板中修改
- **DPI 适配**：界面随系统缩放；准星按物理像素绘制，与游戏画面像素对齐

## 使用方法

- 顶部状态栏四个按钮：**锁定**（鼠标穿透并隐藏控制区）/ **居中** / **设置**（右侧展开设置面板）/ **关闭**
- 未锁定时按住窗口任意空白处拖动即可移动准星位置
- 设置面板分四张卡片：**预设**、**快捷键**、**点心层**、**聚焦层**
  - 预设：下拉框选中即应用；「保存」将当前样式存为预设（同名会询问覆盖）；「删除」移除预设文件
  - 所有参数均为 输入框 + 滑块 双控，改动实时生效并保存
- 锁定时按 **F9**（默认）恢复状态栏并解除穿透

## 配置文件

程序在 exe 同目录读写以下文件，整目录拷贝即为完整迁移：

| 文件/目录 | 说明 |
|---|---|
| `crosshair.ini` | 当前生效的全部配置（样式参数、窗口位置、快捷键） |
| `presets/*.ini` | 已保存的预设，每个预设一个文件 |

## 运行环境

- Windows（32/64 位均可）
- 无需 Qt 环境，解压即用；请解压到有写权限的目录后再运行

## 自行构建

环境：Qt 5.8 + MinGW（qmake 工程）

```bash
qmake MecZuilCrosshair.pro
mingw32-make
```
